# 토마토 데이터 리그

실제 날씨와 스마트팜 생육 기록을 읽고 방울토마토 한 시즌을 운영하는 1인용 성장 게임입니다. 단순히 게이지를 채우는 대신, 매 영농일마다 관수·환기·차광 전략을 선택하고 실제 환경에 맞았는지 채점받습니다. 내 줄기·잎·꽃·열매 기록은 같은 생육 주차의 실제 농가 중앙값과 비교됩니다.

외부 라이브러리, 자체 서버, 설치 과정이 없습니다. `index.html`을 Chrome에서 바로 열면 되고, 인터넷 연결이 없을 때는 마지막으로 저장한 데이터와 표준 재배 환경으로 계속 플레이할 수 있습니다.

## 실행과 기본 플레이

1. `index.html`을 더블 클릭하거나 Chrome 창으로 끌어다 놓습니다.
2. 방울토마토에 이름을 붙여 시즌을 시작합니다.
3. 상단 날씨 카드에서 재배 지역을 검색합니다.
4. 코치 브리핑에서 가장 낮은 성장 요인을 확인합니다.
5. 물·햇빛·흙·생기를 돌본 뒤 균형, 관수, 환기, 차광 중 오늘의 전략을 선택합니다.
6. **오늘 운영 마감**을 눌러 생육 점수와 원인별 결과를 확인합니다.

한 영농일을 마치면 시즌이 진행됩니다. 2개 영농일이 공개데이터의 생육 1주차에 대응하며, 씨앗 → 새싹 → 영양생장 → 개화 → 착과·수확 순으로 변화합니다. 상태가 나쁘면 성장이 멈추지만 죽지 않으며 언제든 회복할 수 있습니다.

## 실제 데이터가 게임에 연결되는 방식

### 1. 농정원 스마트팜 생육 기록: 상대 팀의 선수 능력치

[농림수산식품교육문화정보원(농정원)의 시설 방울토마토 생육·환경 융합 데이터](https://www.data.go.kr/data/15090553/fileData.do?recommendDataYn=Y)의 실제 측정 기록을 주차별 중앙값으로 요약해 게임에 내장했습니다.

- 줄기 굵기, 잎 수, 개화·착과 화방, 열매 수를 2–25주차 벤치마크로 사용합니다.
- 내 기록은 시즌 평균 생육 점수에 따라 농가 중앙값의 약 72–115% 범위에서 계산됩니다.
- 실제 농가의 가지치기와 수확 때문에 다음 주의 잎이나 열매 수가 줄어들 수도 있습니다. 이를 오류로 지우지 않고 실제 시즌의 흐름으로 반영했습니다.
- 화면의 표본 수 `n`은 해당 주차에 생육 측정값이 있는 관측 수입니다. 공개 파일 전체에는 7개 시설의 기록이 포함되어 있습니다.

게임에 내장한 중앙값은 공개 CSV의 2026-08-25 분석 스냅샷입니다. 원본 데이터가 나중에 갱신되어도 오프라인 게임의 시즌 기준은 갑자기 바뀌지 않습니다.

### 2. FAO EcoCrop: 방울토마토의 실제 적정 범위

[FAO EcoCrop 토마토 데이터시트](https://ecocrop.apps.fao.org/ecocrop/srv/en/dataSheet?id=1379)의 범위를 성장 점수에 사용합니다.

- 적정 온도: 20–27°C, 생육 가능 범위: 7–35°C
- 적정 토양 pH: 5.5–6.8, 가능 범위: 5.0–7.5

적정 범위 안에서는 높은 점수를 받고, 가능 범위의 끝에 가까워질수록 온도·토양 점수가 내려갑니다. 이것은 실제 재배 처방이 아니라 공개 범위를 이용한 게임 모델입니다.

### 3. Open-Meteo: 오늘 경기장의 컨디션

[Open-Meteo](https://open-meteo.com/)에서 선택한 도시의 현재 기온·습도·강수·구름·낮/밤과 일별 일사량·FAO 기준 증발산량(ET₀)을 가져옵니다.

- 기온은 FAO 적정 온도 점수에 직접 연결됩니다.
- 일사량은 광량 점수, ET₀와 기온은 하루 수분 소모량에 연결됩니다.
- 고온·건조에는 관수, 고온·다습에는 환기, 고온·강한 일사에는 차광 전략이 유리합니다.
- 날씨는 30분간 저장하고, 6시간을 넘긴 값은 실시간 감소 계산에 쓰지 않습니다.

도시 검색은 위치 권한을 요구하지 않고 사용자가 입력한 이름만 전송합니다.

### 4. ISRIC SoilGrids: 지역 토양 스카우팅

[ISRIC SoilGrids REST API](https://rest.isric.org/soilgrids/v2.0/docs)에서 선택 지역의 0–5cm 표토 pH, 모래·점토, 유기탄소와 질소 예측값을 한 번 조회해 저장합니다.

- 토양 pH는 FAO 적정 pH와 비교해 토양 점수에 반영됩니다.
- API가 응답하지 않거나 지역 자료가 없으면 pH 6.2 표준 상토를 사용합니다.
- 도시 좌표의 야외 표토 예측값은 실제 화분 흙 측정값이 아닙니다. 게임에서는 ‘지역 스카우팅 정보’로만 사용합니다.

SoilGrids는 베타·공정사용 제한이 있어 같은 지역 결과를 180일간 저장하고 불필요한 반복 요청을 하지 않습니다.

## 영농일 점수

하루 점수는 다음 요인을 합산하고 과습성 병해 위험을 감점해 계산합니다.

| 요인 | 비중 | 실제 데이터/플레이 연결 |
| --- | ---: | --- |
| 온도 | 25% | Open-Meteo 현재 기온 ↔ FAO 적정 온도 |
| 광량 | 18% | 일사량 + 햇살방울 활동 |
| 수분 | 18% | 수분 상태 + ET₀ + 관수 전략 |
| 토양 | 15% | SoilGrids pH ↔ FAO 적정 pH + 흙 돌보기 |
| 돌봄 | 24% | 전체 상태, 건강, 오늘 수행한 돌봄 |

등급은 S(95 이상), A(85 이상), B(72 이상), C(58 이상), D로 나뉩니다. 시즌 평점은 지금까지 끝낸 모든 영농일의 평균입니다. 화면의 ‘상위 %’는 이해를 돕기 위한 게임 내 예상치이며 실제 농가 순위가 아닙니다.

## 햇살방울 미니게임

- 키보드: `←` / `→` 또는 `A` / `D`
- 마우스: 게임 화면을 누른 채 좌우로 이동
- 터치: 게임 화면을 손가락으로 좌우 이동

30초 동안 받은 햇살 수에 따라 광량 준비도와 생기가 오릅니다. 햇빛 활동은 수분을 사용하므로 실제 날씨와 수분 상태를 함께 봐야 합니다.

## 저장과 이전

- 행동 직후, 영농일 마감, 탭 전환과 페이지 종료 시 `localStorage`에 자동 저장합니다.
- 브라우저를 닫은 동안의 수분·광량·영양·건강 변화도 다음 접속에 반영합니다.
- 이전 버전에서 키우던 식물은 이름·상태·성장 단계를 보존하고 방울토마토 데이터 시즌의 대응 일차로 자동 이전합니다.
- 새 시즌을 시작하려면 우측 상단 설정에서 **새 씨앗으로 다시 시작**을 누릅니다. 확인 후에만 기록을 삭제합니다.

## 파일과 테스트

- `index.html`: 데이터 리그, 온실, 대화상자와 접근성 구조
- `styles.css`: 360px 이상 반응형 화면, 식물 일러스트와 애니메이션
- `game.js`: 저장, 실제 데이터 수집·캐시, 생육 모델, 돌봄과 미니게임
- `tests/smoke.js`: 무의존성 VM 스모크 테스트

게임 플레이에는 Node.js가 필요 없습니다. 개발 검증은 Node.js가 있는 환경에서 다음과 같이 실행합니다.

```powershell
node tests/smoke.js
```

테스트는 스마트팜 주차 벤치마크 표시, 실제 고온·건조 환경에서 관수 전략의 점수 차이, 영농일 리포트, 성장 단계, 저장 이전, 오프라인 변화, 미니게임과 회복을 확인합니다.

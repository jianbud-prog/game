# 몽글몽글 알숲

신비한 알에서 태어난 작은 친구를 돌보고 성장시키는 1인용 브라우저 게임입니다. 외부 라이브러리, 서버, 네트워크 연결 없이 실행됩니다.

## 실행 방법

1. `index.html`을 더블 클릭하거나 Chrome 창으로 끌어다 놓습니다.
2. 알 속 친구에게 이름을 지어 줍니다.
3. 먹이, 놀기, 씻기, 재우기, 치료 버튼으로 상태를 돌봅니다.

별도 설치나 빌드 명령은 필요하지 않습니다. 게임은 브라우저의 로컬 저장소에 자동 저장되며, 다시 열었을 때 지나간 시간만큼 상태가 반영됩니다.

## 미니게임 조작

- 키보드: `←` / `→` 또는 `A` / `D`
- 마우스: 게임 화면을 누른 채 좌우로 이동
- 터치: 게임 화면을 손가락으로 좌우 이동

30초 동안 떨어지는 간식을 받으면 됩니다. 노란 별은 일반 간식보다 높은 점수를 줍니다.

## 성장과 안전한 초기화

- 성장 단계: 알 → 말랑 아기 → 호기심 꼬마 → 성체
- 성체 모습은 먹이, 놀기, 씻기와 수면 기록에 따라 달라집니다.
- 오래 돌보지 않아도 친구가 사라지지는 않습니다. 아프면 필요한 상태를 회복시키고 치료해 주세요.
- 새로 시작하려면 우측 상단 설정에서 **새 알로 다시 시작**을 누릅니다. 확인 후에만 기존 기록이 삭제됩니다.

## 파일 구성

- `index.html`: 게임 화면과 접근성 구조
- `styles.css`: 반응형 레이아웃, 캐릭터 일러스트, 애니메이션
- `game.js`: 돌봄, 성장, 저장, 시간 경과, 이벤트와 미니게임 로직
- `tests/smoke.js`: 저장과 주요 플레이 흐름을 확인하는 무의존성 스모크 테스트

Node.js가 설치되어 있다면 프로젝트 폴더에서 `node tests/smoke.js`로 로직 검사를 다시 실행할 수 있습니다. 게임 플레이에는 Node.js가 필요하지 않습니다.

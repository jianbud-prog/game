# 포근포근 작은 정원

작은 씨앗을 돌보며 새싹, 나무, 꽃과 특별한 열매로 성장시키는 1인용 식물 다마고치 게임입니다. 외부 라이브러리, 서버, 네트워크 연결 없이 실행됩니다.

## 실행 방법

1. `index.html`을 더블 클릭하거나 Chrome 창으로 끌어다 놓습니다.
2. 씨앗에 이름을 붙이고 화분에 심습니다.
3. 물 주기, 햇빛 받기, 흙 돌보기, 음악 들려주기, 영양제로 상태를 관리합니다.

별도 설치나 빌드 명령은 필요하지 않습니다. 게임은 브라우저 로컬 저장소에 자동 저장되며, 다시 열었을 때 지나간 시간만큼 정원의 상태가 반영됩니다.

## 햇살방울 미니게임

- 키보드: `←` / `→` 또는 `A` / `D`
- 마우스: 게임 화면을 누른 채 좌우로 이동
- 터치: 게임 화면을 손가락으로 좌우 이동

30초 동안 떨어지는 햇살방울을 화분으로 받으면 됩니다. 커다란 햇살은 일반 햇살보다 높은 점수를 줍니다.

## 식물 성장

- 성장 단계: 씨앗 → 새싹 → 나무 → 꽃 → 열매
- 물, 햇빛, 흙과 음악을 돌본 비율에 따라 별빛 열매, 햇살 열매, 이슬 열매 중 하나가 맺힙니다.
- 오래 돌보지 않아도 식물이 사라지지 않습니다. 시들면 부족한 상태를 채우고 영양제를 주세요.
- 새로 시작하려면 우측 상단 설정에서 **새 씨앗으로 다시 시작**을 누릅니다. 확인 후에만 기존 기록이 삭제됩니다.

## 파일 구성

- `index.html`: 정원 화면과 접근성 구조
- `styles.css`: 반응형 온실, 5단계 식물 일러스트와 애니메이션
- `game.js`: 식물 돌봄, 성장, 저장, 시간 경과, 이벤트와 미니게임 로직
- `tests/smoke.js`: 저장과 주요 플레이 흐름을 확인하는 무의존성 스모크 테스트

Node.js가 설치되어 있다면 프로젝트 폴더에서 `node tests/smoke.js`로 로직 검사를 실행할 수 있습니다. 게임 플레이에는 Node.js가 필요하지 않습니다.
